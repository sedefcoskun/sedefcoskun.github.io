# Sedef Coşkun — Portfolio (Dark Rose, final layout)

## Preview
Open `Sedef_Coskun_Portfolio_Final_Preview.html` directly in Chrome/Edge to review the site.

## Publish on GitHub Pages
1. Open the repository `sedefcoskun.github.io`.
2. Replace the old root files with the contents of this ZIP (six files).
3. Keep Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. After deployment, refresh the website (Ctrl+Shift+R).

## Content
Original site structure, animations, six projects, compact Experience and Skills, English/Turkish language switch, Dark Rose colors. No separate certifications panel; the academic/education area links to LinkedIn for additional credentials.

A CV download link is not included until a finalized PDF is available.
