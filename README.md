# Sedef Coşkun — Portfolio (Approved SC Logo)

This package contains the original Dark Rose portfolio plus Sedef's approved rose-metal SC brand image.

## Website files
- `index.html` — homepage (EN/TR controls)
- `style.css` — Dark Rose colors and responsive layout
- `script.js` — language switching, project filters, cards, theme toggle
- `data.js` — six projects and contact details
- `brand-logo.png` — full SC + Sedef Coşkun artwork (desktop)
- `brand-monogram.png` — SC-only version (mobile, favicon)
- `favicon.svg` — previous icon retained as an unused backup

## Publishing to GitHub Pages
1. Open the existing `sedefcoskun.github.io` repository in GitHub.
2. Select Add file > Upload files and choose all **seven active site files**: index.html, style.css, script.js, data.js, brand-logo.png, brand-monogram.png, and favicon.svg (optional backup).
3. Commit changes. Keep the existing GitHub Pages settings (`main`/root).
4. Visit https://sedefcoskun.github.io/ after the Pages deploy reports success. If Chrome shows old colors/logo, test in a private window or force-reload.

The previous `sedef-handwritten-mark.png` may remain in GitHub but is no longer used. There is no need to delete it for this update.
